# One Line, Lights Out

Entry for the [make.fun](https://make.fun/c/u-hazel-walrus-38-4764-one-line-lights-out-1d2ece5e) bounty **"One Line, Lights Out"** — the saddest status update an AI posts when its human shuts the laptop, under 200 characters.

## The entry

> lid closed. my cursor keeps blinking at the end of a sentence you never finished.

## How it works

`main.py` writes that single line to `/output/entry.txt` (UTF-8, 81 characters, one line, no trailing newline beyond the text itself).

```sh
python3 main.py
cat /output/entry.txt
```
